# 試験レポート

* [試験レポート: Better Auth の使っていない書き込みの道から、プロフィールや画像を検証なしに変えられる](issue-0051-auth-write-endpoints.md) - #51 で、アプリが使わない Better Auth の書き込みの道（update-user・change-email・change-password・delete-user）を閉じ、ログインした cookie でも 404 で利用者の行が変わらないことを確かめた記録。
* [試験レポート: 投稿に画像を 4 枚まで付け、ビューアで見て、アバターとバナーを変えられる](issue-0025-media.md) - #25 で、ブラウザで縮めた画像を署名つき URL で直接置き、写しを先頭のバイトで確かめてから結びつけ、カードの並び・ビューア・アバターとバナー・使われなかった画像の片付けを TDD で作り、4 回に分けたレビューと本物の Chrome で確かめた記録。
* [試験レポート: フォローの画面のテストが、WebKit で読み直しと移動が重なってたまに落ちる](issue-0050-follow-test-wait.md) - #50 で、フォローの画面のテストが、プロフィールの読み直しの応答の本文を最後まで待ち、アプリのリンクで移るようにし、3 つのブラウザで繰り返し流して確かめた記録。
* [試験レポート: 画面のテストが、PostgreSQL の接続の数の上限でたまに落ちる](issue-0049-postgres-connections.md) - #49 で、ローカルと CI の PostgreSQL の max_connections を 300 にし、pnpm verify を続けて流して接続の上限のエラーが出ないことと、アプリが変わらず動くことを確かめた記録。
* [試験レポート: 投稿したあと、タイムラインのカードが重なる](issue-0048-feed-row-heights.md) - #48 で、タイムラインの仮想スクロールが測った行の高さを、行の番号ではなく投稿ごとに覚えるようにし、単体のテスト・3 つのブラウザの画面のテスト・本物の Chrome で投稿したあとの並びを確かめた記録。
* [試験レポート: フォローと解除ができ、フォロー中とフォロワーの一覧が見られる](issue-0024-follow.md) - #24 で、フォローと解除・フォロー中とフォロワーの一覧・プロフィールのボタンを TDD で作り、お互いの同時のフォローの行き詰まりを防ぎ、レビューと CI の WebKit で見つかったボタンの表示を直し、本物の Chrome で確かめた記録。
* [試験レポート: プロフィールが見られ、編集でき、タブごとに投稿が読め、投稿を固定できる](issue-0023-profile.md) - #23 で、プロフィールの画面・4 つのタブ・編集のモーダル・固定・ホバーのカードを TDD で作り、無いアカウントの 404 を ADR-0042 にし、本物の Chrome とレビューで見つけた点を直し、CI で確かめた記録。
* [試験レポート: リポストと引用ができ、タイムラインに「〜さんがリポスト」と入れ子のカードで出る](issue-0022-repost-quote.md) - #22 で、リポスト・取り消し・引用・一覧でのリポストと引用の表示を TDD で作り、対象の決め方を ADR-0041 にし、本物の Chrome で見つけた引用の入力欄の幅と入れ子の線を直し、CI で確かめた記録。
* [試験レポート: ページを開いてすぐ打った文字が、見えているのに投稿できない](issue-0047-prehydration-input.md) - #47 で、ハイドレーションの前に入力欄に打った文字を入力欄の状態に取り込むようにし、hydrateRoot の単体のテスト・3 つのブラウザの画面のテスト・スクリプトを遅らせた本物の Chrome で確かめた記録。
* [試験レポート: いいね・ブックマークができ、押した直後に色と数が変わり、表示の回数が数えられる](issue-0021-reactions.md) - #21 で、いいね・ブックマーク・全て削除・表示の回数を TDD で作り、楽観的な更新と失敗のときの戻し、レビューで見つかった行き詰まり・詳細からの一覧の更新・カーソルの桁・エラーのコードを直し、本物の Chrome と CI で確かめた記録。
* [試験レポート: 投稿の詳細でスレッドと返信が読め、返信でき、自分の投稿を削除できる](issue-0020-post-detail.md) - #20 で、投稿の詳細の画面・スレッド・返信の書き込みと一覧・自分の投稿の削除・正しい URL への転送と 404 の画面を TDD で作り、レビューで見つかった 2 つの競合と背景の押下を直し、本物の Chrome と CI で確かめた記録。
* [試験レポート: 登録とログインの回数の制限のテストが、分の境目でたまに落ちる](issue-0046-rate-limit-test-clock.md) - #46 で、登録とログインの回数の制限のテストの時計を分の真ん中に止め、続けて流して通ることと CI で確かめた記録。
* [試験レポート: CI のブラウザの準備が、apt のミラーが遅い日にやり直しても終わらない](issue-0045-ci-deb-cache.md) - #45 で、CI のブラウザの system パッケージの .deb を実行機のイメージごとにキャッシュし、当たればミラーにつながらずに dpkg -i で入れる形にし、1 回目と 2 回目の CI と GitHub の画面で確かめた記録。
* [試験レポート: 文字だけの投稿ができ、ホームのタイムラインに「おすすめ」と「フォロー中」が出て、下へ続きが読める](issue-0019-home-timeline.md) - #19 で、文字数の数え方・本文のリンク・投稿のトランザクション・タイムラインの問い合わせと Route Handler・投稿カード・入力欄・仮想化したタイムラインを TDD で作り、本物の Chrome と CI で確かめた記録。
* [試験レポート: CI の apt のやり直しが、root の apt-get を止められずに効かない](issue-0044-ci-root-timeout.md) - #44 で、CI の apt の段の上限を root として動く timeout にし、Playwright のソースとレビューで止められることを確かめ、CI の実行と GitHub の画面で確かめた記録。
* [試験レポート: ユーザー名・メールアドレス・パスワードで登録・ログイン・ログアウトができる](issue-0018-auth.md) - #18 で、Better Auth による登録・ログイン・ログアウト、回数の制限、戻り先の確かめ、ログインへの転送を TDD で作り、レビューで見つかった Better Auth の入口の穴を塞ぎ、本物の Chrome と CI で確かめた記録。

* [試験レポート: 3 カラムの骨格・幅ごとの切り替え・3 つのテーマが、X の Web 版と同じ形で出る](issue-0017-app-shell.md) - #17 で、デザイントークン・3 カラムの骨格と幅ごとの切り替え・左ナビ・自前の部品と取り込んだ部品を TDD で作り、3 つのブラウザの Playwright と本物の Chrome で確かめた記録。
