# 機能の範囲

- 決定: [ADR-0009](../adr/0009-mimic-x-ui-with-own-brand.md)、[ADR-0011](../adr/0011-polling-and-after-no-queue.md)、[ADR-0015](../adr/0015-timeline-fan-out-on-read.md)
- 作業の順番と分け方は、ここには書かない。GitHub の EPIC と PBI に書く（[ADR-0003](../adr/0003-pbi-epic-issues-with-root-cause.md)）

## 1. 最初の版に入れる

この節の全部がローカルで動くことが、最初のマイルストーンの終わりの条件（[ADR-0019](../adr/0019-first-milestone-runs-locally.md)）。Cloudflare への配備は次のマイルストーンで、機能は増えない。

| 領域 | 機能 |
|---|---|
| 骨格 | 3 カラムの骨格、幅ごとの切り替え、下のタブバー、3 つのテーマとアクセントの色 |
| アカウント | ユーザー名・メールアドレス・パスワードでの登録、ログイン、ログアウト |
| 投稿 | 文字だけの投稿、画像つきの投稿（4 枚まで、代替テキスト）、削除、文字数の輪、モーダルの入力欄、下書きの保存 |
| 会話 | 返信、スレッドの表示、引用、リポストとその取り消し |
| 反応 | いいね、ブックマーク、表示の回数 |
| タイムライン | 「フォロー中」と「おすすめ」のタブ、無限スクロール、「N 件のポストを表示」、スクロールの位置の復元 |
| プロフィール | プロフィールの表示と編集（名前・自己紹介・場所・リンク・アバター・バナー）、各タブ、固定した投稿、フォロー中とフォロワーの一覧 |
| フォロー | フォロー、フォロー解除 |
| 通知 | いいね・リポスト・返信・引用・メンション・フォローの通知、未読の数、「すべて」と「メンション」のタブ |
| 検索 | 本文・ユーザー・ハッシュタグの検索、結果のタブ、トレンド、おすすめのユーザー |
| 表示 | 投稿の詳細、画像のビューア、リンクとメンションとハッシュタグの自動のリンク、相対の時刻、数の省略の表示 |
| 操作 | キーボード操作、ホバーのカード、トースト |
| 設定 | テーマとアクセントの色、アカウントの情報 |

## 2. 後の段階で足す

| 機能 | 足すときに決めること |
|---|---|
| ダイレクトメッセージ | すぐ届ける仕組み（Server-Sent Events と LISTEN / NOTIFY）を ADR で決める |
| メールの確認、パスワードの再設定 | メールを送るサービスを ADR で決める |
| Google と GitHub でのログイン、パスキー | Better Auth のプラグインで足す |
| 投票、予約投稿、GIF、動画 | 動画は変換の仕組みを ADR で決める |
| 返信できる人の指定、ミュート、ブロック、非公開のアカウント | タイムラインと通知の問い合わせに条件を足す |
| リスト | |
| 「おすすめ」の点数での並べ替え | 並べ方とページングを ADR で決める |
| リンクのカード（OGP の取得） | 外へのリクエストの安全な取り方を決める |
| 英語の表示 | 文言の持ち方を ADR で決める |

## 3. 作らない

| 機能 | 理由 |
|---|---|
| Grok、Premium、認証済み組織、収益化、広告 | X に固有の製品 |
| Communities、スペース、ライブ配信 | 学習の目的に対して大きすぎる |
| 暗号化チャット | 同上 |
| スマートフォンのアプリ、公開の API | 1 つの Web アプリに絞る（[ADR-0004](../adr/0004-nextjs-16-all-in-one-app.md)） |
| 管理者の画面、通報の仕組み | 誰でも登録できる形で公開するときに、改めて決める |
