# マイルストーン 1 の探索的テスト（#34）

## 調査日: 2026-11-19

## 1. 方法

- 対象: ブランチ `m1/local-app` の HEAD 216f1b2 を 1 回だけ本番ビルド（`pnpm build`）し、`next start` で動かした。その時点で `pnpm verify` は緑（単体 1001、e2e 294、カバレッジ 100%）
- 試す人を 3 つに分け、それぞれ別のデータベース（`xmodoki_explore_a`〜`c`）と別のポート（3401〜3403）を使った。共有の PostgreSQL と Garage は止めず、通信の切断は Playwright の `context.setOffline` と `page.route` の中断で起こした
- 動かし方: Playwright（Chromium）のスクリプト。作ったアカウントは全部、架空の名前と `@example.test` のメール
- 各ケースは、先に期待を書いてから動かし、数字で結果を残した。1 回だけの事象は再現させてから不具合とした

| 試す人 | 見方 |
|---|---|
| A | 速い連打と二重の送信、途中での通信の切断 |
| B | 長い・変わった入力（絵文字・結合文字・右から左の文字・10 万文字）、狭い画面と拡大 |
| C | 戻る・進む・再読み込み、複数のタブと複数のユーザー |

## 2. 1 巡目の結果

### 2.1 速い連打と二重の送信

| 試したこと | 起きたこと | 判定 |
|---|---|---|
| 「ポストする」を 3 回続けて押す | 投稿は 1 件、投稿の数も 1 | 問題なし |
| いいね・ブックマークを 2・3・7 回続けて押す | 行の数・数字・再読み込みの後の画面が、最後の状態の通りにそろう | 問題なし |
| リポストと取り消しを 1〜3 回、フォローを 2・3・6 回 | 行の数と、フォローする数・される数がそろう | 問題なし |
| 登録とログインで Enter 2 回と押す | 利用者は 1 人、`/home` へ移る | 問題なし |
| 返信・引用・プロフィールの保存・削除の確認を 3 回続けて押す | どれも 1 回だけ効く | 問題なし |
| 10 秒の間に 11 件投稿する | 11 件目で「投稿が多すぎます」と出て、文字は残る | 問題なし |

### 2.2 長い・変わった入力

| 試したこと | 起きたこと | 判定 |
|---|---|---|
| ZWJ の家族・肌の色・旗の絵文字 | そのまま保存され、はみ出さない | 問題なし |
| 右から左の文字（アラビア文字・ヘブライ文字と日本語）、U+202E を閉じる・閉じない | 本文の中だけが反転し、名前や時刻の行は崩れない | 問題なし |
| 幅の無い文字、HTML の文字列 | そのまま保存され、HTML は文字として出る | 問題なし |
| 270 文字の 1 語、220 文字の URL | 1280・360・320px で横にはみ出さない。URL は 23 の重みで数える | 問題なし |
| 140 字の漢字・281 字の英字・10 万字の漢字 | 数の表示が負になり、ボタンが押せない。フォームを直に送っても「本文を確かめてください」で保存されない | 問題なし |
| ハッシュタグ・メンションの境目（`#タグ。`、`#123`、`#🔥`） | X と同じ所でリンクになる | 問題なし |
| 結合文字（か + U+3099、e + U+0301）で投稿する | NFC にそろえて保存される | 問題なし |
| 結合文字の形（NFD）で検索する | NFC で保存した投稿が 0 件（NFC で探すと 1 件）。2 回再現 | **不具合 #66** |
| 本文の前後に空白と改行を入れて投稿する | 空白と 3 行の空行がそのまま保存されて出る（X は取り除く） | **不具合 #67** |
| プロフィールの各欄の長さ・`javascript:` の URL・空の名前 | 全部、文言付きで拒まれる | 問題なし |
| 検索の言葉に `% _ \ ' "`、絵文字、NUL、100 文字 | 5xx が出ず、正しく探す | 問題なし |
| 登録のユーザー名に 2 文字・16 文字・全角・予約語・大文字違いの重複 | 全部拒まれる | 問題なし |

### 2.3 戻る・進む・再読み込み

| 試したこと | 起きたこと | 判定 |
|---|---|---|
| ホーム → 詳細 → 戻る | 元のスクロールの位置（約 250px）に戻る | 問題なし |
| 詳細でいいね → 戻る、ホームで取り消し → 進む | どちらの画面も新しい状態 | 問題なし |
| 投稿のダイアログ・写真の表示で再読み込み・戻る・進む | 再読み込みでは画面として、戻るでは閉じた状態で出る | 問題なし |
| 投稿 → 再読み込み | 投稿は 1 件だけ | 問題なし |
| 詳細の画面で自分の投稿を削除 → 戻る | 消した投稿の詳細がまた出る（再読み込みで 404）。3 回再現 | **不具合 #68** |
| 詳細の画面で返信 → 戻る | ホームのカードが「返信 0・表示 0」のまま（再読み込みで 1・1）。3 回再現 | **不具合 #69** |
| ログアウト → 戻る、`?next=` 付きのログイン | 守られた画面は出ず、ログインの後に元の画面へ移る | 問題なし |

### 2.4 複数のタブと複数のユーザー

| 試したこと | 起きたこと | 判定 |
|---|---|---|
| 同じ人の 2 つのタブで、片方で投稿し、もう片方の「フォロー中」を見る | 新しい投稿の知らせが出る | 問題なし |
| B が投稿を消した後に、A の開いたままの詳細でいいね・返信する | 「見つかりません」の文言が出て、数は増えない | 問題なし |
| A が片方のタブでログアウトし、もう片方で操作する | ログインへ移る | 問題なし |
| A と B が同時にお互いをフォローする、2 つのタブから同時にいいねする | 数がそろう | 問題なし |
| 古いタブでいいね・フォロー・ブックマーク | サーバーの数に落ち着く | 問題なし |

### 2.5 狭い画面と拡大

| 試したこと | 起きたこと | 判定 |
|---|---|---|
| 320・360・375px と、320×225（400%）・640×450（200%）で全部の画面 | 横にはみ出さない。コンソールの誤りと警告は 0 | 問題なし |
| 640px より狭い画面のプロフィールの編集 | 右下に浮かぶ投稿ボタンが「保存」に重なって押せない | **不具合 #65** |
| 高さの低い画面（320×300）の投稿のダイアログ | 浮かぶ投稿ボタンが「ポストする」に重なる。320×225 では下のナビゲーションにも隠れる | **不具合 #65**（同じ原因） |

### 2.6 途中での通信の切断

| 試したこと | 起きたこと | 判定 |
|---|---|---|
| オフラインでいいねし、つながってからもう一度 | トーストで知らせて元に戻り、やり直せる | 問題なし |
| 画像の送信・署名の要求を途中で切る | 「画像を送れませんでした」と出て、投稿は作られない | 問題なし |
| オフラインで投稿する（ホーム・返信・ダイアログ・画像付き） | 画面全体が英語の「This page couldn't load」に変わり、打った文字が消える。つながっても戻らない。5 回再現 | **不具合 #70** |
| オフラインでフォローする | ボタンが黙って元に戻り、何も知らせない | **不具合 #70**（同じ原因） |
| 予期しない例外の画面（上の投稿で見えた） | 英語の Next.js の決まりの画面 | **不具合 #71** |
| オフラインでホームを下まで送る | スピナーが 12 秒以上回り続け、知らせもやり直しも無い | **不具合 #72** |
| オフラインで詳細を開く | ブラウザの「接続できません」の画面（画面ごとの移り変わりに切り替わる） | ブラウザの振る舞い。直さない |

### 2.7 #71 を直す途中で見つけたこと

| 試したこと | 起きたこと | 判定 |
|---|---|---|
| 解読できない `%` を含む URL（`/%ZZ`・`/x/status/%ZZ`・`/api/posts/%ZZ/view`） | 素の「Internal Server Error」（500）。動的でない `/home/%ZZ` は 404 | **不具合 #73** |
| どのルートにも当たらない URL（`/i/zzz` など） | Next.js の英語の黒い 404 の画面（ADR-0039 で範囲の外にしたもの） | 改善の候補。直さない |

### 2.8 環境のこと（アプリの不具合ではない）

- Garage の CORS は決まったオリジンだけを許すので、3401〜3403 のポートからは画像を送れなかった。試す人は `page.route` で中継して確かめた
- ログインしたままログインの画面を開くと、フォームがそのまま出る（X はホームへ移す）。要件に無いので不具合にはせず、改善の候補として残す

## 3. 見つけた不具合と直し方

| issue | 根本原因 | 直し方 | 再現して落ちるテスト |
|---|---|---|---|
| #65 | 浮かぶ投稿ボタンを、投稿のダイアログと設定の画面でも出し、メインの下に余白が無かった | 投稿の画面と設定の画面では出さない。狭い画面のメインの下に、ボタンとナビゲーションの分の余白を取る | `e2e/narrow.spec.ts` › 浮かぶ投稿ボタンと、画面の下の操作（#65） |
| #66 | 検索の言葉とプロフィールの欄を NFC にそろえていなかった | 検索の言葉とプロフィールの欄を `normalize('NFC')` してから使う | `load-search-page.test.ts` › NFD の言葉でも NFC の投稿が見つかる |
| #67 | 投稿の本文の前後を取り除いていなかった | 保存の前と、文字数を数える前に `trim()` する | `create-post.test.ts`・`measure-post.test.ts` |
| #68 | 削除の後に `router.push` で移り、履歴と一覧のキャッシュに消した投稿が残った | `router.replace` で移り、全部の一覧のキャッシュから取り除く（`removePostFromCaches`） | `e2e/post-detail.spec.ts` › 詳細の画面で削除したあと「戻る」でも、消した投稿の詳細は出ない（#68） |
| #69 | 返信と表示の数を、詳細の画面の中だけで増やし、一覧のキャッシュに伝えていなかった | 返信が通ったら返信の数を、表示を数えたら表示の数を、一覧のキャッシュで 1 増やす | `e2e/post-detail.spec.ts` › 詳細で返信して戻ると、ホームのカードの返信と表示の数が増えている（#69） |
| #70 | Server Action の Promise が通信の失敗で投げると、呼ぶ側が受け止めていなかった | 10 か所の呼び出しを `settle` で包み、「通信できませんでした。もう一度お試しください」を出す。フォローも失敗をトーストで知らせる | `e2e/offline.spec.ts`、各部品の「通信が切れて action が失敗」のテスト |
| #71 | `error.tsx` と `global-error.tsx` が無かった | 日本語の誤りの画面と「もう一度読み込む」のボタン（ADR-0062） | `e2e/error-page.spec.ts` |
| #73 | 動的なセグメントの引数を Next.js が解読できず、無い `/400` の画面を描こうとして 500 になる | `proxy.ts` で解読を試し、できなければ `/404` へ書き換える（ADR-0063） | `e2e/malformed-url.spec.ts`、`proxy.test.ts` › 壊れた URL（#73） |
| #72 | オフラインで止まった続きの読み込み（`fetchStatus: 'paused'`）を、読み込み中と同じに扱っていた | 止まっている間は「オフラインです。つながると続きを読み込みます」を出す | `e2e/offline.spec.ts`、`post-feed.test.tsx` › 続きとオフライン（#72） |
