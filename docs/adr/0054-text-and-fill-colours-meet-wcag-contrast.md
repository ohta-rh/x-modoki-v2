# ADR-0054: 文字と塗りに使う色は、X の色を背景と 4.5:1 以上の差がある最も近い濃さに変える

- ステータス: 採用
- 日付: 2026-11-19
- 決定者: エージェント（委任された判断。ADR-0028 によりユーザーに聞かずに決めた。#31 の実装方針「差を満たす最も近い値に変える」に従った）
- 関連: [ADR-0009](0009-mimic-x-ui-with-own-brand.md)、[ADR-0051](0051-theme-from-a-head-script-not-the-root-layout.md)、#31

## 背景

- #31 で、axe-core（WCAG 2.2 の A と AA）を、ルーティングの全部の画面と 3 つのテーマで流した。そこで X の色のままだと、次が `color-contrast` の違反になった（2026-11-19）
  - 投稿のボタン: 青の上の白い文字で 3.0
  - ライトのテーマのリンク: 白の上の青い文字で 3.0
- 6 つのアクセントの色と、3 つのテーマの背景を計算した（`tokens.test.ts`）
  - 白い文字を載せる塗り: 4.5:1 を満たすのは紫だけ。黄色は 1.43
  - ライトのテーマの文字: 紫のほかは全部足りない
  - ディムのテーマの文字: ピンクと紫が足りない
  - いいね（`#F91880`）・リポスト（`#00BA7C`）・危険（`#F4212E`）の文字も、ライトでは足りない
- 行をホバーすると背景が少し変わり（ライトは `#e7e8e8`、ダークは `#171717`）、Firefox の axe はその状態でも違反を出した。ダークの薄い文字 `#71767B` は、ホバーの上で 3.9 だった
- NFR-A11Y-02 は 4.5:1 以上を求め、#31 は「X の値で差が足りない場合は、差を満たす最も近い値に変える」と決めていた

## 決定

- **X の色の変数（`--accent`・`--like`・`--repost`・`--danger`）は、そのまま残す。** 設定の「表示」で選ぶ色の目印として使う
- **文字に使う色は、テーマとアクセントごとの別の変数にする。** `--accent-text`・`--like-text`・`--repost-text`・`--danger-text` を置く。値は、X の色の色相と彩度のまま、明るさだけを変えた最も近い値。条件は、背景とホバーした行の背景の両方に対して 4.5:1 以上。ライトでは暗く、ディムとダークでは明るくする
- **白い文字を載せる塗りは、`--accent-fill`・`--danger-fill` にする。** 白い文字と 4.5:1 以上になる、最も近い暗さの値。黄色だけは、暗くするとくすんだ黄土色（`#8c7500`）になる。だから塗りは黄色のままにして、上の文字（`--on-accent`）を `#0F1419` にする（差 12.9）
- **ダークのテーマの `--text-muted` は `#7B8086` にする**（X は `#71767B`）。ホバーした行の上でも 4.5:1 を満たすため
- Tailwind の `brand`・`like`・`repost`・`danger`・`ring` は文字の色に、`brand-fill`・`on-brand`・`danger-fill` は塗りに結ぶ。タブの下線のような文字の無い塗りは、文字の色のままでよい
- 全部の組み合わせ（テーマ 3 × アクセント 6、背景とホバー）は、`src/_app/styles/tokens.test.ts` が計算して確かめる。画面は `e2e/a11y.spec.ts` が確かめる

## 検討した選択肢

| 選択肢 | 長所 | 短所 |
|---|---|---|
| **X の色を目印に残し、文字と塗りだけを最も近い濃さにする（採用）** | X に近い見た目のまま、全部の組み合わせで 4.5:1 | 変数が増える。ライトのテーマの色は X よりわずかに濃い |
| X の色をそのまま使う | X と同じ見た目 | 18 の組み合わせの多くで AA に届かない。NFR-A11Y-02 に反する |
| 塗りの上の文字を全部黒にする | 塗りの色を変えずに済む | 青・ピンク・紫のボタンが X と大きく違って見える |
| アクセントの色を AA を満たす 6 色に選び直す | 変数が少ない | 設定の色が X と別物になる |

## 結果

- 良くなること: ルーティングの全部の画面が、3 つのテーマで axe の WCAG 2.2 A・AA と best-practice の違反 0（#31）
- 受け入れる負担: ライトのテーマでは、リンクとボタンが X よりわずかに濃い。色を足すときは、文字用と塗り用の値も決める
- 守ること: 文字に X の色の変数を直接使わない。新しい色は `tokens.test.ts` の組み合わせに入れる
