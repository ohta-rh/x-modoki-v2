# 機能の要件

- 出典: [機能の範囲](../architecture/scope.md) の 1 節（13 の領域）。値は [UI/UX 仕様](../architecture/ui-ux.md)、[データモデル](../architecture/data-model.md)、[ルーティング](../architecture/routing.md) から写した。この文書で新しい値は作らない
- ID は `FR-<領域>-<連番>`。いったん付けた ID は、付け直さない・使い回さない
- 確かめ方の層: **単体**（Vitest、純粋な関数と同期のコンポーネント）／**DAL**（Vitest、本物の PostgreSQL に対するデータアクセス層・Server Action・Route Handler）／**画面**（Playwright、Chromium・Firefox・WebKit）
- 「満たす PBI」は、その要件を作る issue。要件とテストの対応の表は #30 で作る
