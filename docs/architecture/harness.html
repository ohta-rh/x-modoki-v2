完了の定義（10 項目、例外なし）

  1. 受け入れ条件を、書いた方法で 1 つずつ確かめた
  2. TDD で作り、赤を記録した
  3. pnpm verify が 0 で終わった
  4. 画面で見える条件に Playwright があり、3 ブラウザで通った
  5. 本物の Chrome で触り、写真を残した
  6. 独立したレビューが APPROVE を返した
  7. その commit の CI が緑
  8. 決定は同じ commit に ADR
  9. 試験レポートと写真を push し、CI が緑
  10. commit・CI・レポートを書いて閉じた

エージェントが決めること、決めないこと

自分で決めて、ADR に残す

  • 設計と道具の選び方（決定者: エージェント）
  • バグの直し方と、直す順番
  • 前提が崩れたときの代わりの方法
  • テストと文書の書き方

決めない（ユーザーのもの）

  • アカウント・支払い・秘密の値（その PBI は blocked）
  • 強制の push、作っていない物を消す
  • 確認を弱める（ブラウザを外すのも ADR とユーザーの判断）
  • マージとリリースの公開（ADR-0029）
