# マイルストーン 1 の探索的テスト（#34）

## 調査日: 2026-11-19

## 1. 方法

- 対象: ブランチ `m1/local-app` の HEAD 216f1b2 を 1 回だけ本番ビルド（`pnpm build`）し、`next start` で動かした。その時点で `pnpm verify` は緑（単体 1001、e2e 294、カバレッジ 100%）
- 試す人を 3 つに分け、それぞれ別のデータベース（`xmodoki_explore_a`〜`c`）と別のポート（3401〜3403）を使った。共有の PostgreSQL と Garage は止めず、通信の切断は Playwright の `context.setOffline` と `page.route` の中断で起こした
- 動かし方: Playwright（Chromium）のスクリプト。作ったアカウントは全部、架空の名前と `@example.test` のメール
- 各ケースは、先に期待を書いてから動かし、数字で結果を残した。1 回だけの事象は再現させてから不具合とした

| 試す人 | 見方 |
|---|---|
| A | 速い連打と二重の送信、途中での通信の切断 |
| B | 長い・変わった入力（絵文字・結合文字・右から左の文字・10 万文字）、狭い画面と拡大 |
| C | 戻る・進む・再読み込み、複数のタブと複数のユーザー |

## 2. 1 巡目の結果

### 2.8 環境のこと（アプリの不具合ではない）

- Garage の CORS は決まったオリジンだけを許すので、3401〜3403 のポートからは画像を送れなかった。試す人は `page.route` で中継して確かめた
- ログインしたままログインの画面を開くと、フォームがそのまま出る（X はホームへ移す）。要件に無いので不具合にはせず、改善の候補として残す

### 4.5 不具合にしなかったこと

- U+200B などの幅の無い文字だけの投稿はできる。FR-POST-03 は「空か空白だけ」を拒むと書いており、これらは Unicode の空白ではない
- 無いユーザーや投稿の画面は「このページは存在しません」と `noindex` を出すが、流して描くので HTTP は 200
- オフラインのいいね・ブックマーク・リポストは、知らせを出さずに待ち、つながると送る（TanStack Query の決まりの動き。#70 の対象の Server Action ではない）
- 別の人の返信が届いても、開いたままの一覧のカードの数は再読み込みまで古い（X も同じ）

| 見方 | 試したこと | 起きたこと | 判定 |
|---|---|---|---|
| 連打 | ADR-0064 の境目（61 秒後、違う画像、同じ画素の再アップロード、消した投稿、2 つの親への同じ返信） | ADR のとおり | 問題なし |
| 連打 | 同じ本文をわざと 5 秒後にもう一度 | 黙って 1 つにまとまる（ADR-0064 が受け入れた負担） | 問題なし |
| 連打 | 2 つのタブから同時に同じ本文 | 2 行（ADR-0064 は 1 つのタブの中のやり直しだけを扱う） | 問題なし（記録だけ） |
| 切断 | オフラインのログイン・登録 | 画面全体が誤りの画面に変わり、入れた値が消える | **不具合 #82** |
| 切断 | オフラインのログアウト | 何も起きず、知らせも無い | **不具合 #82** |
| 切断 | 画像の送信を切ってやり直す、固定と解除の連打、遅らせたフォローの 2・3 回押し | 状態がそろう | 問題なし |
| 入力 | 場所に区切りの無い 30 字 | プロフィールが 320px で 146px はみ出す | **不具合 #80** |
| 入力 | 100 字のハッシュタグ | 話題の一覧が 320px で 627px はみ出す | **不具合 #80** |
| 入力 | 名前が 50 字の人からの通知 | 通知の行が 320px で 281px はみ出す | **不具合 #80** |

| 拡大 | 853×533・427×267・320×200 の主な画面、投稿と編集のダイアログ | 通知と話題のほかは収まる | 問題なし |
| 複数 | 同じ人の 2 つのタブで、片方で下書きを保存し、もう片方で 1 文字打つ | 書きかけが別のタブの下書きに入れ替わる | **不具合 #81** |
| 複数 | 古いタブで別の人としてログインしたあとに投稿する | 新しい人として投稿される（cookie は 1 つ。X も同じ） | 問題なし（記録だけ） |
