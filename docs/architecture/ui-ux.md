# UI/UX 仕様（X の Web 版に合わせる範囲と値）

- 根拠: [X の Web UI/UX 調査](../research/x-uiux.md)（2026-11-18）
- 決定: [ADR-0009](../adr/0009-mimic-x-ui-with-own-brand.md)、[ADR-0014](../adr/0014-tailwind-shadcn-base-ui.md)
- 値の確度: **[V]** は出典で確認できた値、**[A]** は広く報告されている近似値。[A] の値は実装のときに見た目で調整してよい

## 1. 合わせる範囲

| 区分 | 対象 |
|---|---|
| 同じにする | 3 カラムの骨格、sticky で半透明のヘッダー、タブ、投稿カードの並び、スレッドの線、モーダルになる URL、文字数の数え方、ボタンのホバーの振る舞い（Following → Unfollow）、キーボード操作 |
| 近似する | ブレークポイント、配色の hex、アイコン、アニメーション、メディアの格子の比率 |
| 作らない | Grok、Premium、認証済み組織、Communities、広告、暗号化チャット、収益化 |
| 使わない | 「X」「Twitter」の名前とロゴ、Chirp フォント、X のアイコンと画像、実在の投稿やアカウントを装うデータ |

アプリの表示名は「x-modoki」。ロゴ・アイコン・フォントは自前か OSS のものを使う。フッターに「X Corp. とは関係の無い学習用のアプリ」と書く。

## 2. 全体のレイアウト

```
┌──────────┬────────────────────────┬──────────────┐
│ 左ナビ   │ メイン                 │ 右サイドバー │
│ 275px    │ 600px（左右に 1px 線） │ 350px        │
│ sticky   │ sticky ヘッダー 53px   │ sticky       │
└──────────┴────────────────────────┴──────────────┘
```

| 項目 | 値 | 確度 |
|---|---|---|
| 左ナビ（展開） | 275px | [V] |
| 左ナビ（アイコンだけ） | 88px | [A] |
| メイン列 | 600px、左右に 1px の線 | [V] |
| 右サイドバー | 350px、`position: sticky` | [V] |
| ヘッダー | 高さ 53px、半透明の背景と `backdrop-filter: blur(12px)` | [A] |

| 画面の幅 | 振る舞い | Tailwind |
|---|---|---|
| 1280px 以上 | 3 カラム。左ナビは文字つき | `xl:` |
| 1024px 〜 1279px | 3 カラム。左ナビはアイコンだけ（88px） | `lg:` |
| 640px 〜 1023px | 右サイドバーを出さない。左ナビはアイコンだけ | `sm:` |
| 640px 未満 | 左ナビを出さない。下にタブバー、右下に丸い投稿ボタン、ヘッダーの左にアバター（ドロワーを開く） | 既定 |

X の実際のブレークポイントは確認できていない。Tailwind の標準の値に丸める。

## 3. ナビゲーション

| 位置 | 項目（上から） |
|---|---|
| 左ナビ | ロゴ / ホーム / 話題を検索 / 通知 / メッセージ / ブックマーク / プロフィール / もっと見る / 投稿ボタン / アカウントの切り替え（アバター・名前・@handle・「…」） |
| 下のタブバー | ホーム / 検索 / 通知 / メッセージ |

- アイコンは 24px。選んでいる項目は塗りつぶしのアイコンと太字にする
- 通知とメッセージには未読の数のバッジを付ける
- メッセージは後の段階で作る。それまでは項目を出さない

## 5. 投稿カード

```
[アバター 40px] 名前 ✓ @handle · 時刻                     …
                本文（リンク・@メンション・#ハッシュタグはアクセント色）
                [メディア / 引用した投稿 / リンクカード]
                💬 12   🔁 3   ♡ 48   📊 1.2万        🔖  ↗
```

- カード全体が投稿の詳細へのリンク。中のリンクとボタンはそれぞれの動きをする
- 操作の列は左から 返信 / リポスト / いいね / 表示回数 / ブックマーク・共有。ホバーで、その色のアイコンと 10% の濃さの丸い背景を出す
- いいねは押した直後に色と数を変える（楽観的な更新）。ハートは拡大してから戻る。`prefers-reduced-motion` のときは動かさない
- リポストはメニュー（リポスト / 引用）を開く

| 項目 | 規則 | 確度 |
|---|---|---|
| 文字数 | 上限は重みつきで 280。ラテン文字は 1、CJK と絵文字は 2、URL は長さによらず 23。返信の先頭の自動の @メンションと添付は 0。NFC に正規化してから数える。`twitter-text` の `parseTweet` で数える。日本語は実質 140 文字 | [V] |
| 相対時刻 | 60 秒未満 `N秒`、60 分未満 `N分`、24 時間未満 `N時間`、同じ年 `M月D日`、前の年より前 `YYYY年M月D日`。詳細ページは絶対時刻 | [A] |
| 数 | 1 万未満はそのまま（3 桁区切り）、1 万以上 `1.2万`、1 億以上 `3.4億`。英語は `1.2K` / `3.4M` | [A] |
| 長い本文 | タイムラインでは切り詰めて「さらに表示」を出す | [A] |
| メディア | 全体の角は 16px、すき間は 2px。1 枚は元の比率（高さに上限）、2 枚は左右、3 枚は左に大 1 と右に小 2、4 枚は 2×2 | [A] |
| 引用した投稿 | 1px の線と 16px の角の入れ子のカード | [A] |

## 6. タイムライン

- ヘッダーに「おすすめ」「フォロー中」のタブ。選んでいるタブに 4px のアクセント色の下線
- 下まで行くと続きを読み込む（カーソルによるページング）。画面の外のカードは DOM から外す（仮想化）
- 新しい投稿があると、上に「N 件のポストを表示」の丸いボタンを出す。押すまでタイムラインは動かさない
- 戻る操作でスクロールの位置を元に戻す
- 640px 未満では、引っ張って更新できる
- スレッドは、アバターの下の 2px の縦の線でつなぐ。返信には「返信先: @user」を出す
- 読み込み中はアクセント色の円のスピナー。プロフィールと画像は骨組み（スケルトン）

## 7. 投稿の入力

- ホームの上にインラインの入力欄。左ナビの投稿ボタンと `n` キーでモーダル（`/compose/post`）
- 入力欄は内容に合わせて伸びる
- 残りの文字数の輪: 入力すると進む。残り 20 で黄色、0 未満で赤と数字。超えている間は投稿ボタンを押せない
- 画像は 4 枚まで。1 枚ごとに代替テキストを付けられる。絵文字の選択
- 中身があるときに閉じると「破棄 / 保存」を聞く。保存した下書きは次に開いたときに戻す
- 送ったあと、下の中央に「ポストを送信しました」と「表示」のリンクを出す
- 投票・予約投稿・GIF・位置情報・返信できる人の指定は、後の段階で作る

## 8. プロフィール

- バナー（3:1）、重なるアバター、名前、@handle、自己紹介、場所・リンク・登録した月、フォロー中とフォロワーの数
- 自分のプロフィールには「プロフィールを編集」（モーダル）。他人には「フォロー」。フォロー中のボタンはホバーで「フォロー解除」と `--danger` の色になる
- タブ: ポスト / 返信 / メディア / いいね。固定した投稿は上に「固定」と出す

## 9. ほかの画面

| 画面 | 内容 |
|---|---|
| 話題を検索 | 上に検索の欄。トレンド（ハッシュタグの数）と、おすすめのユーザー |
| 検索の結果 | タブ: 話題 / 最新 / ユーザー / メディア |
| 通知 | タブ: すべて / メンション。種類ごとのアイコン（いいねはハート、リポストは矢印、フォローは人）と、アバターをまとめた表示 |
| ブックマーク | タイムラインと同じ並び。「全て削除」のメニュー |
| 設定 | 2 ペイン。640px 未満では 1 ペインずつ |
| ログインしていないとき | 左にロゴ、右に登録とログイン。登録とログインはモーダル |
| 右サイドバー | 検索の欄 / トレンド / おすすめのユーザー / フッターのリンク |

## 10. 操作とアクセシビリティ

| キー | 動き | 確度 |
|---|---|---|
| `n` | 投稿のモーダルを開く | [V] |
| `l` | 選んでいる投稿にいいね | [V] |
| `j` / `k` | 次 / 前の投稿へ | [A] |
| `r` / `t` | 返信 / リポスト | [A] |
| `g` のあと `h` / `n` / `p` | ホーム / 通知 / プロフィールへ | [A] |
| `?` | キーの一覧を出す | [A] |
| `Esc` | モーダルを閉じる | — |

- アバターと名前に約 0.5 秒ホバーすると、プロフィールの小さなカードを出す
- フォーカスの輪は `:focus-visible` のときだけ、2px のアクセント色。ただし、投稿の入力欄のような枠の無いテキストの入力欄は、X と同じく輪を出さない（クリックでも `:focus-visible` になり、四角い輪が出てしまうため。場所は点滅するカーソルで分かる。#19）。枠のある入力欄（登録とログイン）は、枠の色をアクセントの色に変えて示す
- モーダルはフォーカスを中に閉じ込め、閉じたら元の要素へ戻す
- 画像には代替テキストを付ける。アイコンだけのボタンには `aria-label` を付ける
- 文言は日本語を既定にする。時刻と数の形はロケールで切り替える
