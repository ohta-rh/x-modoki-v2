# マイルストーン 1 の振り返り

## 調査日: 2026-11-20

- 読んだもの: マイルストーン「M1: ローカルで全部が動く」の 88 の issue（本文の冒頭の注、根本原因、コメント）、ADR-0001〜0071、全部の試験レポートの「コードレビュー」「見つけた問題」「再試験」、[探索的テストの記録](exploratory-m1.md)、`.claude/rules/` と `CLAUDE.md` の変更の履歴、CI の実行 128 回（成功 101、失敗 17、取り消し 10）と、どの試験レポートにも無い失敗 3 回のログ
- 基にした版: `m1/local-app`（PR #40）
- 分け方: 「前提が崩れた」（道具やライブラリが思ったとおりに動かなかった、ADR を置き換えた）、「ルールがあいまいだった」（ルールや issue が足りず、間違いかやり直しになった）、「やり直した」（レビューで戻した、赤い CI を直した、エージェントの間違い）
- 「機械にした」は、lint・スクリプト・CI・テストが、同じことが起きたら落ちること
